# الأكاديمية — تنفيذ الخادم الداخلي وحدوده

## الحالة الفعلية

`academy/service.py` خادم أعمال فعلي بقاعدة SQLite ومعاملات ذرية، و`academy/server.py` ينقل طلبات JSON عبر HTTP محلي. الاختبارات تستخدم قواعد بيانات حقيقية وطلبات HTTP حقيقية وحسابات تجريبية. **لم يُنشر الخادم، ولم يُربط تطبيق Android به بعد، ولا توجد جلسات تدريس حية أو معلمون معتمدون فعليًا.** دفتر Android المحلي يستمر دون تغيير. لا إذن إنترنت جديد في APK.

## الحسابات والخصوصية

- حساب مدير يُنشأ مرة واحدة خارج واجهة الشبكة. المدير ينشئ حسابات المعلمين وأولياء الأمور؛ لا تسجيل مدير من العميل ولا حسابات أطفال.
- كلمة المرور 15–128 حرفًا، مع scrypt: N=131072، r=8، p=1 وملح عشوائي مستقل. لا كلمة مرور صريحة في قاعدة البيانات. المرجع: [OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html). هذا اختيار تقني وليس شهادة تدقيق أمني.
- رمز جلسة عشوائي؛ المخزن بصمته فقط. تنتهي الجلسة بعد ساعة. تسجيل الخروج يبطل الرمز، وتغيير كلمة المرور يبطل جميع جلسات الحساب. إيقاف الحساب يبطل جلساته فورًا.
- خمس محاولات دخول فاشلة تحظر المحاولة لهذا الاسم خمس دقائق، بما في ذلك الاسم غير الموجود. يلزم حد مستقل لكل IP وعلى مستوى الخدمة قبل أي نشر خارجي.
- ملف الطالب اسم مستعار، ولي أمر مالك، ووقت إقرار الموافقة. **الإقرار ليس تحققًا مستقلًا من العمر أو هوية ولي الأمر أو علاقة الوصاية**. يُحظر فتح الخدمة للأطفال حتى اكتمال التحقق وسياسة الاحتفاظ والفحص المختص.
- لا تسجيلات صوتية أو مصحف مولّد أو كلمات مرور أو رموز في سجل التدقيق؛ يسجل معرفات داخلية وأفعالًا وأوقاتًا فقط. قد تُعد المعرفات بيانات شخصية مستعارة؛ مدة الاحتفاظ النهائية لم تعتمد.
- حذف الطالب يحذف الربط والجلسات والبلاغات وخطط المراجعة والملاحظات التابعة داخل القاعدة بمعاملات ومفاتيح خارجية. الحذف المنطقي لا يضمن محو نسخ القرص أو النسخ الاحتياطية؛ لم تُنفّذ سياسة النسخ الاحتياطي المشفر للخادم بعد.

## واجهة العمليات

كل عملية تتطلب Bearer صالحًا، عدا `/v1/login`. أُدرجت الصلاحيات داخل الخدمة نفسها؛ لا تعتمد على إخفاء أزرار الواجهة.

| العملية | من يملك تنفيذها | السلوك |
|---|---|---|
| account_create / account_disable | المدير | حساب معلم/ولي أمر فقط؛ الإيقاف يقطع الوصول ويلغي الحجوزات التابعة |
| password_change / logout | صاحب الحساب | التحقق من كلمة المرور الحالية وإبطال الجلسات / إبطال الجلسة الحالية |
| teacher_submit / teacher_profile | المعلم | تقديم مؤهل كادعاء غير موثق / عرض حالة ملفه |
| teacher_review_queue / teacher_review | المدير | عرض بيانات المراجعة الخاصة؛ قرار بشري مع مرجع دليل، دون تحقق آلي |
| teachers | الحسابات المسجلة | دليل الأسماء المعتمدة داخليًا فقط؛ المؤهلات والأدلة ليست عامة |
| student_create / student_delete / student_export | ولي الأمر المالك | إقرار بالغ وموافقة مطلوبة؛ حذف متسلسل؛ تصدير ملفه وخططه وملاحظاته |
| enroll / unenroll | ولي الأمر المالك | ربط بمعلم اجتاز المراجعة الداخلية؛ الإلغاء يقطع وصول المعلم ويلغي الحجوزات |
| availability_add / availability_remove | المعلم المعتمد / صاحب الموعد | فترات 5–120 دقيقة؛ منع التداخل؛ منع حذف موعد محجوز دون إلغاء الجلسة |
| availability | الحسابات المسجلة | مواعيد مستقبلية لمعلم معتمد داخليًا |
| book | ولي الأمر المالك | ضمن تفرغ المعلم؛ منع تداخل الطالب أو المعلم بمعاملة ذرية |
| students / lessons | المدير، المالك، المعلم المرتبط والمعتمد | المعلم يرى جلساته فقط؛ حساب آخر لا يصل للطالب أو ملاحظاته |
| lesson_update | الأطراف المخوّلة | إلغاء الحجز؛ إتمام الجلسة وملاحظتها للمعلم المسند وبعد نهاية الموعد فقط |
| plan_create / plans / plan_observe | المعلم المرتبط / الأطراف المخوّلة | خطة نطاق آيات مثبت ببيانات السور وبصمتها؛ ملاحظة معلم منفصلة عن تقييم ولي أمر ذاتي |
| complaint_create / complaints | الطرف المخوّل / صاحب البلاغ أو المدير | بلاغ خاص؛ لا إغلاق ذاتي من المعلم لبلاغ ولي الأمر |
| complaint_resolve / audit | المدير | توثيق معالجة بشرية / آخر 200 حدث تدقيق |

تغيير مؤهلات المعلم يعيد الحالة إلى «معلق»، ويلغي الحجوزات ويقطع الوصول إلى الطلاب حتى مراجعة جديدة. إيقاف ولي الأمر يزيل روابط معلميه بطلابه ويلغي الحجوزات. لا توجد عملية لإصدار إجازة أو اعتماد شرعي أو قرار لجنة.

الأوقات أعداد صحيحة UTC بالثواني، ونطاق الحجز خلال 366 يومًا. خطط المراجعة داخل سورة واحدة في هذه المرحلة؛ لا تحمل نص القرآن. بيانات العناوين مأخوذة من `surah-metadata.txt` بعد مطابقة SHA-256 وعدد 114/6236، ولا يُستدعى نموذج لغوي لإنتاجها.

## النقل والتشغيل الداخلي

المساران: `POST /v1/login` بجسم `{login,password}` و`POST /v1/operation` بجسم `{action,data}` ورأس `Authorization: Bearer …`. لا مفاتيح أو رموز جاهزة داخل المستودع.

النقل يلتزم **127.0.0.1 فقط**، ويرفض Host غير محلي وOrigin المتصفح وJSON بمفاتيح مكررة وطلبات تزيد على 16 KiB. مهلة الاتصال خمس ثوانٍ، والخادم تسلسلي لمنع أعمال scrypt غير محدودة بالتوازي. لا CORS أو سجل أجسام الطلبات. `http.server` من المكتبة القياسية ليس خادم إنتاج؛ **لا يُعرض للعامة ولا يُمرر عبر نفق**. مرجع المعاملات: [Python sqlite3](https://docs.python.org/3/library/sqlite3.html).

للمطورين داخل بيئة اختبار خاصة: وحدة `academy.server` تدعم قاعدة بيانات يحددها المشغل وتهيئة المدير بكلمة مرور تفاعلية مخفية؛ لا تُمرر كلمة مرور في سطر الأوامر. بيانات القاعدة ليست ملفًا يضاف إلى Git؛ صلاحية الملف 0600. التشغيل لا ينشر تطبيقًا ولا يرسل رسالة.

## ما تبقى قبل الاستخدام الحقيقي

ربط Android بعميل HTTPS وواجهة تسجيل وصلاحيات، واجهة إدارة للمراجع البشري، هوية المدير والتحقق من المعلمين والوصاية، استرداد الحساب وMFA، استضافة معتمدة مع TLS ومحدّدات حمل ونسخ مشفر وحذف واحتفاظ مدققين، تدقيق اختراق مستقل، وسياسة البلاغات والتواصل وجلسات تدريس خاصة. هذه متطلبات إصدار غير مكتملة؛ لا تُستبدل بنتيجة الاختبارات ولا تُعلَّم مراحل الأكاديمية مكتملة.
