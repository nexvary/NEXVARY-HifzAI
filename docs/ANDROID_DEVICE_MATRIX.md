# مصفوفة Android الفعلية والمعلقة

آخر دليل مرجعي 4660508: Pixel 6 على API 26 و35، 12 اختبارًا عاديًا و3 اختبارات واجهة بخط 1.5 لكل API، مع 84 PNG مثبتة ببصمات المصدر والصور. يشمل الصوت الحقيقي للميكروفون وMediaPlayer والاستدلال بنغمة رياضية فقط؛ لا قياس لدقة كلام أو تلاوة.

أُضيف مسار CI مستقل لهاتف Nexus S الصغير (API 26) وتابلت Pixel C (API 35)، بالاختبارات نفسها والخطين. **هذه إضافة اختبار، وليست نتيجة نجاح مفترضة.** تعطي PROOF_MANIFEST معلومات حجم الشاشة والكثافة والموديل والـAPI والخط والبصمات. يضبط السكربت الخط الافتراضي إلى 1.0 صراحة قبل التشغيل الأول.

تقتصر مساحة المحتوى على نحو 840dp في النوافذ الواسعة، مع هوامش لا تقل عن 18dp على الهاتف؛ تحفظ الألوان والتنقل والوظائف الحالية وتمنع امتداد سطر القراءة بلا حد عبر التابلت.

يجب ربط كل نتيجة بآخر SHA في Actions. صور الواجهة لا تثبت تدقيق ضبط المصحف، واختبار التابلت المحاكى لا يثبت جهازًا فعليًا. تبقى هواتف ARM الفعلية وTalkBack والذاكرة والطاقة والحرارة والتقييم البشري ضمن موانع القبول النهائي. لا تنشر APK من مستودع عام أو تقدم هذه الأدلة كاعتماد علمي.
