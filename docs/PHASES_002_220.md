# Roadmap: stages 002–220

This is a **backlog, not a claim of completion**. Each stage requires code, review and evidence before it can be checked. Order may be adjusted for safety and dependencies.

**Already prototyped separately:** Arabic RTL Android screens, reading/masking/recall, local review, memory fingerprints, early word-similarity search, corpus structural validator, CI configurations. These still need successful CI and on-device verification. Audio, Quranic corpus, teacher verification and speech recognition remain unfinished.

Definition of Done: acceptance tests + traceable commit + successful CI (where applicable), preservation of previously working features, documented Quran authenticity and permissions.
