# نقل نسخة اختبار داخلية مشفرة

يبقى رفع APK واضح من المستودع العام محظورًا، ويبقى Release محظورًا. عند طلب بناء داخلي بذكر `[internal-apk]` في رسالة commit على dev/foundation، يشفر CI نسخة Debug بعد الاختبارات والفحوص إلى OpenSSL CMS باستخدام AES-256-GCM وRSA-OAEP-SHA256. يرفع ciphertext وبيانات SHA-256 فقط لمدة يوم. لا يمكن تثبيت الملف المشفر كأنه تطبيق.

شهادة INTERNAL_BUILD_TRANSPORT_CERT.pem عامة ومؤقتة ولا تثبت هوية عالم أو مراجع ولا موافقة. المفتاح الخاص لا يدخل Git أو GitHub أو APK؛ يبقى خارج المستودع لدى جلسة البناء الداخلية. لا يستخدم التطبيق هذه الشهادة أو الشبكة. إذا انتهت صلاحية الشهادة يلزم تبديل المفتاح العام قبل طلب نقل جديد؛ لا يتأثر البناء المعتاد دون العلامة.

يُفك النقل خارج GitHub داخل بيئة الاختبار الخاصة، مع فحص SHA-256 للـZIP والمحتوى المشفر، ونجاح التحقق من GCM، ثم SHA-256 للـAPK وحجمه وربطه بـHEAD. لا يُتاح الملف النهائي قبل نجاح جميع الفحوص. الملفات المؤقتة غير الموثقة ليست مرشحًا للتثبيت. دقة التسميع والتجويد والحقوق الخارجية وفحص العرض والقبول البشري تظل غير معتمدة. ليست هذه حزمة اللجنة ولا إذن نشر أو طلب إرسال رسمي.
